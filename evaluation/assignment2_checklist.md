# Assignment 2 demonstration checklist

- [ ] Sign in as a student and show identity.
- [ ] Retrieve own student details, fee and scholarship status.
- [ ] Attempt to access another student's record and show denial.
- [ ] Show the denial in the trace and audit log.
- [ ] Submit a registered email change request and show pending approval.
- [ ] Sign in as admin and reject it; verify the email did not change.
- [ ] Submit another request and approve it; verify the change executes only after approval.
- [ ] Attempt to save an OTP/password and show that memory blocks it.
- [ ] Save a safe preference.
- [ ] Run evaluation and show accuracy/pass rate, latency and token usage.
- [ ] Compare measurements with Assignment 1 results.
